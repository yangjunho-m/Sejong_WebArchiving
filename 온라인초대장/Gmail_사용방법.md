# Gmail용 초대장

최신 브라우저용 초대장을 기준으로 다시 제작했습니다. 기존 온라인초대장.html은 유지됩니다.

## 직접 보내기

1. Gmail용_온라인초대장.html을 Chrome 또는 Edge에서 엽니다.
2. 화면이 로드되면 Ctrl+A, Ctrl+C로 복사합니다.
3. Gmail 편지쓰기 본문에 Ctrl+V로 붙여넣습니다. 일반 텍스트 모드는 해제합니다.
4. 받는 사람과 제목을 넣고, 본인에게 먼저 시험 발송합니다.

HTML 파일 자체를 첨부하거나 HTML 소스 코드를 붙여넣는 방식은 사용하지 않습니다. EML을 지원하는 메일 프로그램에서는 Gmail용_메일초안.eml을 사용할 수도 있습니다.

## 파일

- 온라인초대장.html: 편집 가능한 기존 브라우저용 원본
- Gmail용_온라인초대장.html: Imgur 이미지를 불러오는 Gmail 복사용 본문
- Gmail용_미리보기.html: 로컬 gmail-assets를 불러오는 미리보기
- Gmail용_메일초안.eml: 외부 이미지 방식의 새 이메일 초안
- gmail-assets/: 새 애니메이션과 안내문·버튼 이미지, 확인용 미리보기
- gmail-settings.json: 이미지 주소와 링크 설정
- gmail_build.py: 새 생성 스크립트

Gmail에서 배치와 폰트가 바뀌지 않도록 상단은 하나의 GIF, 하단은 이미지로 제작했습니다. WEBSITE, INSTAGRAM, CONTACT는 각각 별도의 링크입니다. CONTACT는 tel:02-3408-3323입니다. 버튼 이미지 셀의 주변 여백도 같은 링크로 클릭됩니다.

실제 메일 발송은 수행하지 않았습니다. 이미지 표시에는 인터넷 연결이 필요하며 수신자의 외부 이미지 표시 설정에 따라 달라질 수 있습니다. 일정은 원본 표기 그대로 유지했습니다.

## 다시 생성

링크나 이미지 주소만 바꾼 뒤 실행:

    python gmail_build.py --html-only

이미지까지 다시 생성:

    python gmail_build.py

이미지를 다시 만들면 gmail-assets의 파일을 호스팅하고 gmail-settings.json의 직접 이미지 주소를 갱신해야 합니다. 이미지 생성은 저장된 1080px 디자인 좌표와 온라인초대장.html의 안내 문단을 사용합니다. 브라우저 HTML의 CSS 좌표를 수정했다면 생성 스크립트의 해당 좌표도 함께 수정해야 합니다.
