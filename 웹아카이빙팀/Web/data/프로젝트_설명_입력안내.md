# 프로젝트 설명 입력 안내

`projects.json`에서 작품의 `id` 또는 `title`을 찾아 아래 두 항목에 입력합니다.

- `summary`: 디자이너 상세 페이지에 표시할 작품 소개
- `description`: 프로젝트 상세 페이지에 표시할 작품 설명

두 설명은 각각 독립적으로 표시됩니다. 빈 문자열이면 해당 설명은 표시하지 않습니다.

## 입력 예시

아래는 두 설명 항목만 발췌한 예시입니다. 기존 작품의 나머지 항목은 그대로 유지합니다.

```json
{
  "summary": "디자이너 상세에 들어갈 작품 소개를 입력하세요.",
  "description": "프로젝트 상세에 들어갈 작품 설명을 입력하세요."
}
```

## 작성 규칙

- 작품 ID, 이미지 경로, 디자이너 연결 항목은 변경하지 않습니다.
- 문장 안의 큰따옴표는 `\"`로 입력합니다.
- 줄바꿈이 필요하면 문자열 안에 `\n`으로 입력합니다.
- 마지막 항목 뒤에는 쉼표를 넣지 않습니다. JSON에는 주석을 넣을 수 없습니다.
