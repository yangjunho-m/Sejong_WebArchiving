# 홈 레이아웃

home-layout.css는 index.html에서만 마지막으로 로드합니다. 다른 페이지 및 700px 이하 모바일 배치는 유지합니다.

데스크톱 기준: 좌우 60px, 12개의 동일한 유동 열, 거터 20px. 1440px에서는 콘텐츠 너비 1320px, 열 너비 약 91.667px입니다. 최대 너비는 제한하지 않아 Stretch로 동작합니다.

소개 영역은 기존 화면에서 추정했습니다. 위원회·푸터는 이후 전달된 그리드 스크린샷의 열 위치를 반영했습니다.

- 소개 로고: 4~9열 (6열).
- 소개글·포스터·운영 정보: 2~11열 (10열).
- 포스터: 10열 안에서 같은 너비 2개, 사이 20px, 원래 비율 유지.
- COMMITTEE 제목: 2열 시작.
- 명단: 7~11열 (5열). 부서명은 7열 시작(2열 폭), 이름은 9열 시작(3열 폭), 사이 20px.
- 푸터: 로고 1~2열, Instagram 3~4열, Behance 5~6열, Vimeo 7~8열, 주소 9~12열.

701~1100px에서는 메뉴를 로고 아래에 배치하고, 명단을 4~11열로 넓히며, 푸터 주소를 다음 행으로 옮깁니다. 모바일은 기존 배치를 유지합니다.

섹션의 기존 상하 여백은 유지하고, 소개 섹션의 고정 최소 높이는 제거해 콘텐츠에 맞게 늘어나도록 했습니다. 위원회 부서 간 80px, 한영 간 8px, 푸터 주소 항목 간 4px은 유지합니다.

첨부된 피그마 간격 반영(701px 이상): 로고→소개글 120px, 소개글→포스터 80px, 포스터→운영 시간 120px, 운영 시간→오프닝 안내 120px. 소개글 마지막 문단의 하단 margin은 0으로 제거해 텍스트 박스 끝에서 포스터까지 80px이 되도록 합니다. 모바일 간격은 기존 값을 유지합니다.
