# BUTTON UP! 인터랙션

세종대학교 디자인이노베이션 졸업전시 `BUTTON UP!`을 위한 참여형 웹 인터랙션입니다.

사용자는 첫 단추 키워드를 고르고, 선택한 단추들을 직접 배치해 선으로 연결한 뒤, 마지막에 영수증 형태의 결과물을 확인합니다.

## 실행

Node.js 20 이상에서 실행합니다.

```bash
npm start
```

기본 주소는 아래와 같습니다.

```text
http://127.0.0.1:4173
```

Windows에서는 `start-server.bat`으로도 실행할 수 있습니다.

## 테스트

```bash
npm test
```

현재 테스트는 학생/작품 데이터, 검색, 연결 규칙, BMP 생성, 서버 접근 제한을 확인합니다.

## 주요 구조

```text
index.html              앱 진입점
server.mjs              로컬 정적 서버
data/catalog.json       학생, 키워드, 작품 데이터
img/                    화면과 영수증에 사용하는 이미지 자산
font/                   프로젝트 폰트
scripts/app.js          화면 전환과 인터랙션 로직
scripts/model.js        데이터 검색, 선택, 연결 모델
scripts/receipt.js      실제 출력/저장용 영수증 캔버스 생성
scripts/receipt-preview.js 화면 표시용 영수증 미리보기
scripts/style.css       전체 스타일
tests/                  자동 테스트
```

서버는 런타임에 필요한 `index.html`, `scripts/`, `data/catalog.json`, `img/`, `font/`만 제공합니다. 원본 엑셀이나 검수 데이터는 브라우저에 노출하지 않습니다.

## 화면 흐름

1. 시작 화면
   움직이는 키워드 그래픽과 시작 버튼을 보여줍니다.

2. 인트로 화면
   `BUTTON UP!` 로고와 중앙 단추 이미지를 보여준 뒤 선택 화면으로 전환됩니다.

3. 단추 선택 화면
   학생 이름이나 키워드로 검색할 수 있고, 선택한 단어 칩은 하단에 표시됩니다. 칩 영역은 가로 스크롤을 지원하며, 오른쪽에는 fade 효과가 적용되어 있습니다.

4. 단추 잇기 화면
   선택한 단추들을 드래그로 배치하고, 클릭한 순서대로 선을 연결합니다. 물건 위 도구로 크기와 회전을 조절할 수 있습니다.

5. 영수증 결과 화면
   사용자가 만든 연결 패턴을 영수증 형태로 보여줍니다. QR 영역, 처음으로 버튼, 하단 안내 문구가 함께 표시됩니다.

## 최근 반영 내용

- 선택 화면 진입 시 중앙 단추가 키워드 이미지로 자연스럽게 전환되도록 조정했습니다.
- 단추 선택 화면의 칩 영역 높이, x 버튼 크기, overflow/fade 처리를 조정했습니다.
- 단추 잇기 화면의 안내 문구에서 `클릭한 순서대로`를 강조했습니다.
- 상단 카테고리 텍스트에서 가운데 `x`를 제거하고 간격을 넓혔습니다.
- 마지막 영수증 화면의 QR 위치를 조금 왼쪽으로 옮겼습니다.
- 마지막 영수증의 상단 `forward, BUTTON UP!` 텍스트를 이미지 자산 `img/forward_buttonUp.png`로 교체했습니다.
- 영수증 안의 작은 디자인 로고는 `img/receipt-design-logo.png`를 사용합니다.
- 영수증 내부 키워드 칩과 섹션 여백을 줄여 하단 안내 문구가 더 잘 보이도록 조정했습니다.
- 마지막 화면의 안내 문구는 `사용자님이 연결한 첫단추를 인쇄 중입니다. 60초 뒤에 첫 화면으로 돌아갑니다.`로 표시됩니다.
- 영수증 인쇄 버튼과 준비 중 안내 텍스트는 제거했습니다.

## 영수증 출력

영수증은 두 방식으로 생성됩니다.

- 화면 미리보기: `scripts/receipt-preview.js`
- 실제 출력/저장용 캔버스: `scripts/receipt.js`

두 파일 모두 같은 결과를 보여주도록 관리해야 합니다. 영수증 상단 로고, 단추 패턴, 선택한 단어, 선택한 학생, 추천 졸업전시작 정보가 포함됩니다.

현재 QR은 임시 placeholder 이미지입니다. 실제 다운로드 URL이나 저장 로직은 아직 연결되어 있지 않습니다.

## 데이터

기본 데이터는 `data/catalog.json`을 사용합니다. 데이터 재생성용 스크립트는 `scripts/import_data.py`입니다.

```bash
python scripts/import_data.py
```

원본 엑셀 또는 검수 데이터가 바뀌면 importer를 다시 실행한 뒤, 검색과 선택 결과가 정상인지 확인해야 합니다.
