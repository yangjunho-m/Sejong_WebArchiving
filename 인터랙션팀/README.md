# BUTTON UP! 인터랙션팀

2026 세종대 졸업전시 체험형 인터랙션 개발본. 기존 `새 폴더`의 에셋을 보존하고 이 폴더 안에 독립 앱을 추가했습니다.

## 실행

에셋 경로는 `img/photo/`(사진), `img/letter/`(단어 SVG), `font/`(폰트)입니다. `data/catalog.json`과 `scripts/import_data.py`도 이 구조를 사용합니다.

Node.js 20 이상에서 `start-server.bat`을 실행하거나 이 폴더에서 `npm start`를 실행한 뒤 http://127.0.0.1:4173 에 접속합니다. 패키지 설치 없이 작동합니다. 서버는 이 컴퓨터에서만 접속할 수 있습니다.

검증: `npm test`. 데이터 재생성: Python 3에서 `python scripts/import_data.py`. 기존 엑셀은 수정하지 않습니다. `data/catalog.json`은 생성 파일입니다.

## 현재 구현

2026-09-21 업데이트: 첫 화면은 `img/btn_mini.png`, 두 번째 화면은 `img/btn.png`를 사용합니다. 영수증은 `src/receipt.js`의 공통 렌더러로 화면·PNG·512px 1bit BMP를 생성합니다. 큰 타이틀, 단추와 단어 그래픽, 선택 태그와 추천 작품을 반영했습니다. 타이틀과 학과 표기는 제공된 폰트로 재현했으며 원본 로고 SVG 적용은 별도입니다. 브라우저 인쇄에는 80mm 폭과 내용에 맞는 페이지 높이를 지정합니다. 프린터 드라이버에서도 80mm 용지를 선택해야 하며 실물 출력은 아직 검증하지 않았습니다.

- 흐르는 단어 SVG 랜딩, 시작 전환, 원형 이미지 캐러셀과 탐색 슬라이더
- 이름·국문/영문 단어 검색, 학생 설명 모달, 선택 추가·취소
- 학생별 선택(같은 단어를 쓰는 학생도 개별 선택), 현재 2–8개 선택
- 단추 드래그/방향키 이동, 확대·축소·회전, 시작/끝을 차례로 클릭해 연결, 선 삭제, 되돌리기
- 모든 단추가 연결되면 결과 생성, SVG 단어와 연결선을 합성한 그래픽, 선택 기반 문구, 관련 학생과 작품 표시
- 512px 너비의 1bit BMP 영수증 저장, 운영체제 인쇄 대화상자
- 2분 무조작 초기화, 모션 감소 설정, 작은 화면 대응

## 아직 확정·구현이 필요한 부분

이 버전은 기능 검토용이며 최종 납품본이 아닙니다.

1. 피그마 flow 화면의 기본 배치와 스타일을 참고했습니다. motion 내부의 상세 수치, Receipt pattern 규칙, 최종 컴포넌트 수치는 추가 대조가 필요합니다. 현재 패턴은 단어 SVG의 위치·크기·회전과 연결선을 보존하는 임시 규칙입니다.
2. 선택 수 2–8개와 결과 설명 문장은 개발용 기본값입니다. 최종 선택 수와 해석 문구를 확정해야 합니다.
3. `data/review.json`의 참가 여부 3행은 원본 값이 혼재합니다. 임의로 제외하지 않았습니다. 전시 운영 전 확정 명단으로 다시 생성해야 합니다. 학번과 원본 검토 열은 브라우저 데이터에 포함하지 않습니다.
4. 작품 위치 데이터가 없어서 위치를 생성하지 않았습니다. 현재 `location: null`이며 화면에는 준비 중으로 표시됩니다. 위치를 수동 입력한 뒤 importer를 다시 실행하면 덮어쓰므로, 최종 위치 입력 방식을 추가해야 합니다.
5. QR 다운로드는 아직 미구현입니다. 휴대폰이 접근할 배포 주소, 결과 저장·만료 정책을 정한 뒤 추가합니다.
6. USB 직접 인쇄, 용지 없음/오프라인 감지, 재출력과 자동 커터는 미구현입니다. 현재 인쇄는 브라우저 인쇄이며 저장 BMP는 512px/1bit/180dpi 메타데이터입니다. SRP-330II 드라이버 및 제조사 SDK 또는 Windows 인쇄 브리지를 기기에서 검증해야 합니다.
7. BMP와 브라우저 인쇄는 경로가 다릅니다. 브라우저 인쇄는 1bit 변환이나 오토커팅을 보장하지 않습니다. 실물 출력에서 72mm 인쇄 폭과 512 dot 정합성을 확인해야 합니다.
8. 이 폴더는 부스 인터랙션 앱입니다. 졸업전시 본 웹사이트의 별도 디자인·페이지 범위는 아직 반영하지 않았습니다.
